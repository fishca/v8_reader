# Инструкция по началу разработки на Visual Studio 2022 (Windows)

Эта инструкция поможет вам настроить окружение и начать разработку портированной версии проекта **v8_reader** на базе **wxWidgets** в среде **Visual Studio 2022** на Windows.

## 1. Предварительные требования

Убедитесь, что у вас установлены следующие компоненты:

### 1.1. Visual Studio 2022
*   **Версия:** Community, Professional или Enterprise (2022 год или новее).
*   **Рабочие нагрузки (Workloads):**
    *   При установке выберите: **"Разработка классических приложений на С++"** (Desktop development with C++).
    *   Убедитесь, что выбраны компоненты:
        *   `MSVC v143 - VS 2022 C++ x64/x86 build tools`
        *   `Windows 10/11 SDK`
        *   `CMake tools for Windows` (обычно установлен по умолчанию).

### 1.2. Библиотека wxWidgets
Для Windows рекомендуется использовать предварительно скомпилированные библиотеки или собрать их самостоятельно.

**Вариант А: Использование готовых бинарников (Рекомендуется для старта)**
1.  Скачайте установщик для вашей версии MSVC с официального сайта: [wxWidgets for Windows](https://www.wxwidgets.org/downloads/).
    *   Ищите версию, соответствующую вашему компилятору (например, **wxWidgets-3.x.x-Setup.exe** для **Visual Studio 2022 (v143)**).
    *   Выберите архитектуру (обычно **x64**).
2.  Запустите установщик.
3.  Путь установки по умолчанию: `C:\wxWidgets\`. Запомните этот путь.
4.  Установщик обычно автоматически собирает библиотеки при первом запуске или предлагает сделать это. Если нет — перейдите к шагу "Сборка библиотек" ниже.

**Вариант Б: Сборка wxWidgets из исходников (Если нужны специфичные настройки)**
1.  Скачайте исходный код (`.7z` или `.zip`) с сайта wxWidgets.
2.  Распакуйте в `C:\wxWidgets\`.
3.  Откройте решение для вашей версии VS:
    *   Путь: `C:\wxWidgets\build\msw\wx_vc17.sln` (для VS 2022).
4.  Откройте в Visual Studio.
5.  В обозревателе решений выберите конфигурацию:
    *   **Release** (или Debug, если планируете отлаживать саму библиотеку).
    *   Платформа: **x64**.
6.  Найдите проект `wxbase` и `wxmsw` (основные библиотеки).
7.  Нажмите правой кнопкой на решение -> **Build Solution** (Ctrl+Shift+B).
    *   *Примечание:* Сборка может занять 10-20 минут.

## 2. Настройка переменных окружения

Чтобы CMake и Visual Studio могли найти библиотеку, задайте системную переменную.

1.  Нажмите `Win + R`, введите `sysdm.cpl` и нажмите Enter.
2.  Перейдите на вкладку **Дополнительно** -> **Переменные среды**.
3.  В разделе **Переменные среды пользователя** (или системы) нажмите **Создать**:
    *   **Имя переменной:** `WXWIN`
    *   **Значение:** `C:\wxWidgets\` (путь, куда вы установили wxWidgets).
4.  Нажмите **ОК** для сохранения.
5.  **Перезапустите Visual Studio**, чтобы она подхватила новую переменную.

## 3. Создание решения в Visual Studio 2022

Мы будем использовать встроенную поддержку CMake, так как это современный стандарт для кроссплатформенных проектов.

### Шаг 3.1: Клонирование репозитория
1.  Создайте папку для проекта, например: `D:\Dev\v8_reader_wx`.
2.  Откройте терминал (Git Bash или PowerShell) в этой папке.
3.  Клонируйте ваш новый репозиторий:
    ```bash
    git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ> .
    ```

### Шаг 3.2: Открытие проекта в VS
1.  Запустите **Visual Studio 2022**.
2.  Выберите **"Открыть локальный папку"** (Open a local folder).
3.  Укажите путь к папке с проектом (`D:\Dev\v8_reader_wx`).
4.  Visual Studio автоматически обнаружит файл `CMakeLists.txt` (который вы создадите согласно инструкции `instruction.md`) и начнет настройку.

### Шаг 3.3: Настройка CMake Presets
В нижней панели статуса или в меню **Представление (View) -> Другие окна (Other Windows) -> Параметры CMake для...** проверьте конфигурацию.

VS должна автоматически создать пресеты. Убедитесь, что используется компилятор **MSVC**.
Если `CMakeLists.txt` настроен верно, он найдет библиотеки через переменную `WXWIN`.

Пример минимального `CMakeLists.txt` для старта (сохраните в корень проекта):

```cmake
cmake_minimum_required(VERSION 3.20)
project(v8_reader_wx LANGUAGES CXX)

set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

# Поиск wxWidgets
# Переменная WXWIN должна быть установлена в системе
if(DEFINED ENV{WXWIN})
    set(wxWidgets_ROOT_DIR $ENV{WXWIN})
endif()

find_package(wxWidgets COMPONENTS core base REQUIRED)

if(wxWidgets_FOUND)
    include(${wxWidgets_USE_FILE})
    message(STATUS "wxWidgets found: ${wxWidgets_LIBRARIES}")
else()
    message(FATAL_ERROR "wxWidgets not found! Set WXWIN environment variable.")
endif()

# Добавление исполняемого файла
add_executable(v8_reader_win
    src/main.cpp
    src/app.cpp
    src/main_frame.cpp
    # Добавьте сюда остальные файлы по мере переноса
)

target_link_libraries(v8_reader_win PRIVATE ${wxWidgets_LIBRARIES})
target_include_directories(v8_reader_win PRIVATE include)
```

## 4. Структура папок для начала работы

Создайте следующую структуру в вашем репозитории перед началом кодинга:

```text
v8_reader_wx/
├── .gitignore
├── CMakeLists.txt          # Файл сборки
├── README.md               # Документация
├── include/                # Заголовочные файлы
│   └── core/               # Логика парсинга (из старого проекта)
│   └── gui/                # Заголовки форм wxWidgets
├── src/                    # Исходные файлы
│   ├── main.cpp            # Точка входа
│   ├── app.cpp             # Класс приложения wxApp
│   ├── main_frame.cpp      # Главное окно
│   └── core/               # Реализация логики парсинга
├── resources/              # Иконки, изображения
└── tests/                  # Юнит-тесты (будущее)
```

## 5. Первый запуск и отладка

1.  В верхнем меню выберите конфигурацию: **x64-Debug** (или Release).
2.  Нажмите **Сборка всех (Build All)** (Ctrl+Shift+B).
    *   Следите за окном "Выходные данные" (Output). Ошибки линковки чаще всего связаны с неверным путем к wxWidgets или несоответствием версии RTL (Debug/Release).
    *   *Важно:* Для отладки вашего кода используйте **Debug** версию wxWidgets. Для релиза — **Release**. Смешивать их нельзя.
3.  Если сборка успешна, нажмите **Запуск (Run)** (зеленая стрелка). Должно открыться пустое окно приложения.

## 6. Типовые проблемы и решения

| Проблема | Решение |
| :--- | :--- |
| **CMake не находит wxWidgets** | Проверьте переменную среды `WXWIN`. Перезапустите VS. Убедитесь, что пути не содержат кириллицу. |
| **Ошибки линковки (LNK2038)** | Несовпадение версий RTL. Убедитесь, что вы линкуете `wxbase32u.lib` (Release) для конфигурации Release и `wxbase32ud.lib` (Debug) для Debug. Обычно `find_package` делает это автоматически, если собраны обе версии. |
| **Отсутствуют заголовки** | Проверьте директиву `#include <wx/wx.h>` и пути в `target_include_directories`. |
| **__fastcall ошибки** | Удалите все упоминания `__fastcall` из кода ядра перед компиляцией в GCC/Clang/MSVC режиме. В MSVC этот ключ игнорируется или требует специфичных настроек, лучше убрать совсем. |

## 7. Дальнейшие шаги

1.  **Перенос ядра:** Скопируйте файлы `Class_1CD.cpp/h`, `Common.cpp/h` и другие нефункциональные файлы из старого проекта в папку `src/core`.
2.  **Очистка кода:** Удалите `#include <vcl.h>`, замените типы данных Borland на стандартные C++.
3.  **Создание GUI:** Начните с реализации `Main Frame` согласно `instruction.md`, используя дизайнер форм (wxFormBuilder) или код вручную.
4.  **Тестирование:** Напишите простой тест на чтение файла `.1CD` и вывод количества таблиц в консоль или лог-окно.
